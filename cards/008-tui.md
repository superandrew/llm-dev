# 008 - Lab TUI

`llm tui`: one screen with the models, their state and their latest sweep, to serve,
stop, download and benchmark without typing commands. Standard library `curses`.
All logic lives in functions without curses; only `_loop` touches the terminal.
Long work runs as a child `bin/llm` process, so the TUI never blocks and adds no logic
of its own.

## llmdev/tui.py

    @dataclass
    class State:
        rows: list            # one dict per model, see build_rows
        selected: int = 0
        message: str = ""
        job: object = None    # the running child process, or None
        job_label: str = ""
        job_log: str = ""

    def build_rows(registry, statuses, summaries) -> list[dict]
    def job_command(action, name, llm_path) -> list[str]
    def render_lines(state, width) -> list[str]
    def handle_key(state, key, start_job) -> bool
    def poll_job(state, read_last_line) -> None
    def run_tui(root) -> int

- `build_rows`: sorted by name, one dict per model with keys `name`, `backend`,
  `healthy`, `pid`, `prefill_tps`, `decode_tps`. `statuses` maps name to the dict of
  `server.status`, `summaries` is the list from `lab.latest_sweeps`. No summary -> None
  for both speeds.
- `job_command`: `[sys.executable, llm_path, action, name]`.
- `render_lines`: a title line; a header; one line per row with `>` in front of the
  selected one and `*` after the name when healthy, None speeds shown as `-`; an empty
  line; the job line `running: LABEL - LAST LOG LINE` when a job runs, otherwise
  `message`; the last line is exactly
  `up/down select  s serve/stop  p pull  b sweep  r refresh  q quit`. Every line is cut
  to `width` and no line ends with spaces.
- `handle_key` returns False only for `q`. Keys are the characters `"s" "p" "b" "r"
  "q"` and the strings `"up"` and `"down"`:
  - up/down move `selected` and stop at the ends. No rows: nothing happens.
  - `s`: `stop` when the selected row is healthy, otherwise `serve`. `p`: `pull`.
    `b`: `sweep`, only when healthy, otherwise `message` = `NAME is not healthy`.
    Each calls `start_job(action, name)`.
  - While a job runs, `s`, `p` and `b` only set `message` = `job running`, and
    `start_job` is not called.
  - `r` sets `message` to `""`; refreshing is done by `_loop`.
  - any other key: nothing.
- `poll_job`: job None -> nothing. Otherwise `job_log = read_last_line()`; when
  `job.poll()` is not None: `message` = `LABEL done` for returncode 0, otherwise
  `LABEL failed (N)`, then `job` = None and `job_label` = `""`.
- `run_tui(root)`: `curses.wrapper` around `_loop`. `_loop` uses `getch` with a 1 second
  timeout, reloads the registry, `server.status` and `lab.latest_sweeps` from `root`
  every 5 seconds and after each job, maps `curses.KEY_UP/KEY_DOWN` to `"up"/"down"`, and
  starts each job with `subprocess.Popen` writing stdout and stderr to
  `root/state/tui-job.log`, with `start_new_session=True`. It never stops a running
  job when it exits. Registry and server errors go to `message`, they do not end the TUI.

## llmdev/cli.py

Add subcommand `tui` calling `tui.run_tui(ROOT)`. Import `tui` inside that branch only,
so that the other commands do not need `curses`. Keep everything else identical.

## tests/test_tui.py

Never start curses, a process or a socket. Cover: `build_rows` with and without summary
and its order; `job_command`; `render_lines` selected marker, healthy marker, `-` speeds,
width cut, no trailing spaces, last line text, job line; `handle_key` up/down at the ends,
empty rows, `s` serve and stop, `p`, `b` healthy and unhealthy, job running blocks all
three, `q` returns False; `poll_job` with no job, running, done, failed.
