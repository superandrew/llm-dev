# 005 - `llm` command line

## llmdev/cli.py

    ROOT = Path(__file__).resolve().parent.parent   # holds models.toml
    def main(argv=None) -> int

argparse subcommands (state dir `ROOT/state`, runs dir `ROOT/runs`):

- `list` - one line per model: name, backend, model, ctx, port.
- `serve NAME` - `server.start`; print "started pid N", or "already serving
  at URL" when it returns None.
- `stop NAME` - print "stopped" or "not running".
- `status [NAME]` - JSON list of `server.status` for one or all models.
- `bench NAME [--words 2000] [--max-tokens 128] [--repeat 2]` - fails with
  exit 1 and a message if `server.health` is False; otherwise runs
  `bench.run` `repeat` times with the same prompt (the second run shows the
  prompt cache) and prints a JSON list. Appends each result as one JSON line,
  with an ISO timestamp, to `ROOT/runs/bench.jsonl`.
- `run CARD --model NAME [--repo .] [--message TEXT]` - fails if the server is
  not healthy; parses the card, calls `runner.run_card` with
  `extra=message`, prints the meta JSON; exit 0 when passed, else 1.

RegistryError, ServerError, CardError -> message on stderr, exit 1.

## bin/llm

Executable Python script (`#!/usr/bin/env python3`): adds ROOT to `sys.path`
and calls `sys.exit(main())`.
